# CHSH Bell Inequality Violation Under Noise: A Threshold Analysis for Near-Term Quantum Devices

**Authors:** Arhaan Sareen, Aditya Saxena
**Affiliation:** QSYS 2026, Institute for Quantum Computing, University of Waterloo

---

## Overview

This repository contains the LaTeX manuscript, simulation code, and hardware results for our paper deriving and measuring the **decoherence threshold** p\* — the minimum noise rate at which a Bell state can no longer violate the CHSH inequality.

The central result is an exact, closed-form threshold under global depolarizing noise:

```
p* = 1 - 1/√2 ≈ 0.2929
```

We derive this analytically (via Pauli tracelessness), verify it numerically across 600 configurations, compare three noise models (depolarizing, dephasing, amplitude damping), and validate on real IBM quantum hardware.

---

## Key Results

### Decoherence Thresholds (simulation)

| Noise Model | Critical rate p* | Notes |
|-------------|-----------------|-------|
| Global depolarizing | **0.2929** (exact) | Analytical + numerical |
| Amplitude damping | 0.2308 | Numerical |
| Local dephasing | 0.1782 | Most destructive — targets coherences directly |

Dephasing is ~40% more destructive than depolarizing because it directly attacks the off-diagonal density matrix elements that carry CHSH correlations.

### Hardware Validation on IBM ibm_fez

All four Bell states were tested on real IBM superconducting hardware (4096 shots):

| Bell State | Hardware \|S\| | Violates classical bound? |
|------------|---------------|--------------------------|
| \|Φ+⟩ | 2.570 | Yes |
| \|Φ-⟩ | 2.608 | Yes |
| \|Ψ+⟩ | 2.549 | Yes |
| \|Ψ-⟩ | 2.510 | Yes |

Mean \|S\| = 2.559 (classical bound = 2.0, Tsirelson bound ≈ 2.828). Effective hardware noise rate p_eff ≈ 0.095 — well below the threshold of 0.293.

## Setup

```bash
git clone <repo-url>
cd bell-paper
pip install -r code/requirements.txt
```

IBM Quantum hardware (optional — simulations run without it):

```bash
export IBM_QUANTUM_TOKEN="your_token_here"
```

---

## Running the Simulation

```bash
python code/run_benchmark.py
```

Sweeps all 4 Bell states × 3 noise models × 50 noise rates. Runs in ~30 seconds.

## Running on Real Hardware

```bash
export IBM_QUANTUM_TOKEN="your_token_here"
python code/run_hardware.py
```

Submits 16 circuits (4 Bell states × 4 measurement settings) to IBM hardware. Results saved to `code/results/hardware_results.json`.
